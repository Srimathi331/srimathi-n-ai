# Srimathi N — Portfolio

Personal portfolio of **Srimathi N**, a third-year AI & Data Science student building toward an AI Engineer / SDE career.

## Tech Stack

- **Framework:** React 19 + TanStack Start (SSR)
- **Router:** TanStack Router (file-based)
- **Styling:** Tailwind CSS v4 + shadcn/ui
- **Build:** Vite 7
- **Language:** TypeScript

```bash

# Start dev server
npm run dev

# Build for production
npm run build
```
